# 🤖 Agentic AI & Automation

One of my main engineering interests is building **AI systems that don't just generate text — they execute actions.**

I work with agentic architectures where AI agents can:

```text
┌──────────────────────────────────────────────────────┐
│                    AI AGENT                          │
├──────────────────────────────────────────────────────┤
│                                                      │
│   🧠 Memory          → Persistent context            │
│   🛠️ Tools           → Execute application actions  │
│   🎯 Goals           → Autonomous decision making   │
│   📦 Records         → Create & manipulate data     │
│   🔌 APIs            → External integrations        │
│   💬 Channels        → WhatsApp / IG / Facebook     │
│                                                      │
└──────────────────────────────────────────────────────┘
```

These systems combine **traditional software engineering, APIs, business logic and LLMs** to automate real operational workflows.
